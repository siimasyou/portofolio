# Portofolio Atin Nur'jannah

Situs portofolio statis (HTML, CSS, JavaScript) tanpa proses build.

## Cara membuka
Buka `index.html` di browser, atau jalankan server lokal dari folder ini:

    npx serve .

## Struktur
- `index.html`: isi halaman
- `css/style.css`: gaya dan tema warna (variabel di `:root`)
- `js/main.js`: interaksi 3D, carousel, kartu pengalaman, salin kontak
- `assets/img/`: foto dan poster konten
- `assets/logos/`: logo Canva, PowerPoint, Excel, Word

## Mengubah konten
- Teks: edit `index.html`. Daftar konten carousel ada di `js/main.js` (`works`), pengalaman di `xp`.
- Warna: ubah variabel di bagian atas `css/style.css`.
- Font dimuat dari Google Fonts, jadi perlu internet agar tampil sesuai desain.
